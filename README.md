# Turbo Robot

Небольшая коллекция экспериментальных проектов. В репозитории теперь есть тренажёр английских слов **English Bloom**.

## English Bloom

Интерактивное веб-приложение для изучения английской лексики в формате красивых карточек.

### Как запустить

1. Откройте папку `english_vocab_app`.
2. Запустите любой статический сервер (например, `python -m http.server`) или просто откройте файл `index.html` в браузере.
3. Переключайтесь между карточками, отмечайте знакомые слова и отслеживайте прогресс.

### Возможности

- Плавный интерфейс с неоновой подсветкой.
- Карточки с транскрипцией, переводом, контекстом и тематическими тегами.
- Кнопки для повторения сложных слов и отметки изученных.
- Прогресс-бар, показывающий количество выученных слов.

Добавляйте собственные слова в массив `words` в файле `script.js`, чтобы расширить тренировку.
